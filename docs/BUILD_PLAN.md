# Suggested Hackathon Build Plan (4–6 hours)

**0:00–0:30 — Setup & contracts.** Run starter; inspect skills, JSON schemas, database, API and sample fixtures. Assign ownership. Choose primary AI provider; note API billing separately from consumer subscriptions.

**0:30–1:30 — Universal URL + resume.** Implement robust extraction for 2–3 sites with fallback, resume PDF/DOCX ingestion, data normalization, deduplication and job fit explanations.

**1:30–2:30 — AI drafts & validation.** Replace heuristic with LLM calls using the `prompts/` templates, verified candidate facts, explicit structured output and claim checking. Generate PDF/DOCX if time.

**2:30–3:30 — Application workflow.** Implement a permitted ATS integration or browser-assisted workflow for a supported site. Add review, confirmation capture, status machine, idempotency and retry visibility. Do not attempt unsafe bypasses.

**3:30–4:30 — People + outreach + tracker.** Add verified public contact discovery, approved professional email integration, tailored drafts, reply classification, opt-out tracking, dashboard. LinkedIn connection requests can be manually sent with prepared copy when automation is restricted.

**4:30–5:30 — Export & portability.** Export six skills and source; test from a clean second account/computer; improve setup instructions. Run tests and fix errors.

**5:30–6:00 — Final judging prep.** Show a complete end-to-end workflow. Keep logs/confirmation evidence. Record what is actually real vs demo and what requires manual action.

## Priority if you fall behind

1. Honest, complete resume + URL → tailored draft → contact draft → tracked application flow.
2. One authorized live integration with verified end-to-end confirmation.
3. More supported job sites and scale to 10 submissions.
4. Email replies and follow-up; skill portability.
5. Advanced employee similarity research, analytics and additional AI models.
