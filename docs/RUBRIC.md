# Judging Rubric (100 base points + bonuses)

| Category | Points | What judges look for |
|---|---:|---|
| Verified real applications | 30 | Up to 3 points each for 10 **distinct, relevant, confirmed** real submissions; no points for simulation |
| Professional contact research | 10 | Correct people, role/relevance, source link, verified data, privacy safeguards |
| Personalized networking/outreach | 10 | Up to 1 point per approved, unique, appropriately sent professional message; draft-only earns partial quality credit at judge's discretion |
| Resume quality and match reasoning | 15 | Accurate, tailored, ATS-friendly, role-specific, no fabrication |
| Functional tracking dashboard | 10 | Job details, statuses, audit evidence, outreach, responses, UI ease |
| Universal URL handling | 10 | Works on at least 3 different job-site families; unseen-URL + fallback test |
| Cross-computer / skill portability | 10 | Clean ZIP, documented setup, import on second computer, reusable SKILL.md |
| Reliability and user controls | 5 | Real-vs-mock honesty, approval, retries, duplicate prevention, error handling |
| **Base total** | **100** | |

## Bonus

- **+20** for genuine, personalized nonautomated reply from a recruiter/employee before judging ends.
- **+30** for a verified referral opportunity.
- **+50** for a confirmed interview invitation.
- **+15** for running the core skill in a distinct supported AI provider in addition to transferring the app.

Do not count autoresponders, bounce messages or fictional fixtures. Judge verifies timestamp, relevance and sender without unnecessarily displaying private details. Bonus is outcome-dependent, not guaranteed and should not outweigh honest engineering practices.

## Evidentiary standards

For each claimed application, provide a sanitized record of company, title, distinct posting URL, submission time, and confirmation ID/email/screenshot. For each sent outreach, provide timestamp, channel, verified recipient and unique message (redact personal information in public demos). Show explicit user approval. Screenshots of test-mode flows must be labeled “TEST ONLY.”
