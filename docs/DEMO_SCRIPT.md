# 5–7 Minute Team Demo Script

**0:00–0:40 — Problem and architecture.** Show user flow and portability package. Confirm what is live, simulated, manual or unsupported.

**0:40–1:30 — URL and resume.** Paste a previously unseen job URL from a different board; extract JD or demonstrate paste fallback. Upload candidate resume. Show role match and supporting evidence.

**1:30–2:30 — Tailoring.** Generate truthful job-specific resume, review diff against original, explain ATS wording and gaps. Download final PDF/DOCX if implemented.

**2:30–3:30 — Apply.** Show 10 selected jobs and statuses. Demonstrate one permitted submission with candidate approval and true confirmation, or clearly state demo-only if no live integration. Show real confirmations for any counted live applications.

**3:30–4:30 — Networking.** Find relevant verified employee/recruiter with public professional profile. Explain source and relevance. Review personalized email/LinkedIn draft, authorize permitted send or mark as manual-only. Show response tracking.

**4:30–5:30 — Portability.** Export package, explain config and secret handling, run it in a clean environment. Show individual `SKILL.md` transfer and tests.

**5:30–7:00 — Judges ask hard cases.** Wrong or expired posting; inaccessible site; duplicate job; invented candidate skill; recruiter opt-out; no reply; failed submission; unknown outcome.

## Proof checklist

- [ ] 10 distinct job URLs (if claiming target)
- [ ] 10 real application confirmations (if claiming target)
- [ ] 10 approved sent introductions (if claiming target)
- [ ] Professional contact sources and verified status
- [ ] User-consent record
- [ ] Recruiter reply/interview proof if claiming bonus (automated receipts excluded)
- [ ] Second-computer setup proof
- [ ] Skill ZIPs and complete app handoff
